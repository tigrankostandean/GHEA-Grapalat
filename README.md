# GHEA Grapalat

GHEA Grapalat is an official open-source Unicode font family designed by Edik Ghabuzyan in 2008. It supports Armenian, Latin, Cyrillic, and Greek alphabets, including all necessary ligatures, punctuation marks, numerals, and basic mathematical symbols. 

In 2010, by the Decision N 1259-Ն of the Government of the Republic of Armenia, GHEA Grapalat was approved as an official font for state official document circulation and was declared public property.

## Font Details

- **Designer:** Edik Ghabuzyan
- **Release Year:** 2008
- **Styles Included:** Regular, Italic, Bold, Bold Italic
- **Category:** Sans Serif (Առանց ծայրատների)
- **Official Status:** Official state document font of the Republic of Armenia
